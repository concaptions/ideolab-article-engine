# IdeoLab: where the topics came from

Every topic on this site's list, the customer question behind it and the group that
question belongs to. Written by `scripts/engine/topics.mjs`, which reads the company's
own source of truth and ICP, asks what the buyer wants to know, turns each answer into
a search phrase, and keeps only the phrases real searches cluster around.

Newest at the bottom. Nothing here was chosen by hand.
