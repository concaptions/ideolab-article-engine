# Blog Topic Backlog (seed clusters)

The autopilot picks the money page with the fewest published posts, then the
best-scoring unused keyword in that cluster (DataForSEO first, this table as
fallback). Keep slugs kebab-case containing the keyword.

Seed one cluster per money page. Give each cluster 2-4 DataForSEO seed keywords
and 5-10 keyword ideas with an angle - the angle is what stops the writer from
producing the same generic post every competitor already has.

## Cluster: /services (DataForSEO seeds: "example seed 1", "example seed 2")

| Keyword idea | Angle |
|---|---|
| example keyword one | The specific take that makes this post different |
| example keyword two | Pillar: the full system applied to this audience |

## Cluster: /pricing (seeds: "example pricing seed")

| Keyword idea | Angle |
|---|---|
| how much does X cost | Honest cost breakdown; when NOT to buy |
| X pricing comparison | Us vs alternatives, with real trade-offs |
